Simatwaz Destroyer — Connection Diagnostic

This page checks whether this browser can establish WebSocket connections to two Deriv endpoints. It does not log in, request account details, or place trades.

Safety: Do not enter or paste an API token on this page. The newer public endpoint is read-only market data; it cannot place trades.

wss://api.derivws.com/trading/v1/options/ws/public
Not tested yet
Tap “Test both connections again”.

How to read the result

Connected means the browser completed the WebSocket handshake with that endpoint. It does not prove trading will work.

Handshake error / timeout means this test could not connect. It does not by itself identify whether the cause is the browser, network filtering, server policy, or another issue.

If Test B connects but Test A fails, we have evidence the phone can reach at least one Deriv WebSocket endpoint. The two endpoints are not interchangeable: Test B is public/read-only.
